# BCET Hub 🚀

An open-source, lightning-fast utility web app built for students of Bengal College of Engineering & Technology (BCET), Durgapur. Access daily class routines, mess menus, live class trackers, and induction schedules instantly—with offline support.

## ✨ Features

* **⚡ Fast & Offline Access:** PWA-ready; install it straight to your home screen to check routines without opening a browser.
* **📅 Class Routines:** Section-wise timetable viewer for 1st year and beyond.
* **🍽️ Hostel Mess Menu:** Real-time dinner/lunch updates with batch timings and a complete 7-day menu.
* **🎯 Induction Tracker:** Stay updated with the 21-day induction program schedule, guest speakers, and venues.
* **🛠️ Manager Portal:** Integrated dashboard allowing designated managers to update site data seamlessly.

## 🛠️ Tech Stack

* **Frontend:** HTML5, HTMX, CSS3, JavaScript, Python (Django) 
* **Styling:** Responsive modern UI crafted with custom CSS

## 📥 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have Git and Python installed on your machine.

### Installation & Running

1. Clone the repo:
   ```bash
   git clone https://github.com/bcetians/BCET-Hub.git
   ```
2. Navigate to the project directory:
   ```bash
   cd BCET-Hub
   ```
3. Set up a virtual environment (recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```
4. Install dependencies (if applicable):
   ```bash
   pip install -r requirements.txt
   ```
5. Run the development server:
   ```bash
   python manage.py runserver
   ```

Open your browser and head to `http://127.0.0.1:8000/` to view the app.
